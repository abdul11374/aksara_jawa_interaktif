📝 Aksara Jawa Interaktif

Aksara Jawa Interaktif adalah sebuah website edukatif berbasis HTML, CSS, dan JavaScript yang dirancang untuk membantu pengguna — terutama pelajar SMA — dalam belajar mengenal huruf-huruf Aksara Jawa secara menyenangkan melalui mode belajar dan kuis interaktif.

🎯 Tujuan Proyek

Menumbuhkan minat belajar budaya dan bahasa daerah, khususnya Aksara Jawa.

Membuat media pembelajaran yang menarik, interaktif, dan mudah diakses.

Mengembangkan keterampilan digital siswa dengan teknologi web dasar.

💡 Fitur Utama
🔹 1. Mode Belajar

Menampilkan seluruh huruf Aksara Jawa beserta contoh katanya.

Desain berbentuk kartu interaktif (card) agar mudah diingat dan menarik secara visual.

Dapat digunakan secara offline setelah diunduh.

🔹 2. Mode Kuis Interaktif

Berisi 15 soal acak seputar Aksara Jawa.

Soal terdiri dari tiga pilihan jawaban.

Dilengkapi timer (10 detik) untuk setiap soal.

Efek audio berbeda saat jawaban benar (benar.mp3), salah (salah.mp3), atau waktu habis (timeup.mp3).

Setelah selesai, muncul popup skor akhir.

🔹 3. Desain Modern dan Responsif

Tampilan menggunakan gradien warna lembut, efek animasi hover dan fade-in.

Responsif di layar laptop maupun ponsel.

⚙️ Teknologi yang Digunakan
Komponen	Deskripsi
HTML5	Struktur halaman dan konten
CSS3	Tampilan modern dengan animasi dan warna gradien
JavaScript (ES6)	Logika kuis, timer, skor, dan interaksi pengguna
🚀 Cara Menjalankan Proyek

Unduh semua file proyek.

Pastikan struktur folder sudah sesuai seperti di atas.

Buka file index.html menggunakan browser (Google Chrome / Edge / Firefox).

Klik “Belajar Aksara Jawa” atau “Main Kuis” untuk mulai belajar.

💡 Tidak memerlukan koneksi internet, bisa dijalankan secara offline.

🧠 Ide Pengembangan Selanjutnya

Menambahkan fitur pencocokan (drag & drop) antara huruf dan kata.

Menambahkan tingkatan kesulitan (mudah, sedang, sulit) dalam kuis.

Fitur poin dan leaderboard untuk kompetisi antar siswa.

Integrasi materi sejarah dan filosofi Aksara Jawa.
